# ADR-0004: Redefinição do escopo de cobertura FIWARE

Data: 2026-08-09
Status: Aceito

## Contexto

Uma análise de arquitetura comparando o diagrama de referência do projeto, a coleção Postman associada, e o código-fonte real concluiu que o sistema hoje cobre apenas o Orion Context Broker (e mesmo assim parcialmente — sem subscriptions efetivamente enviadas), formulando a lacuna como "o projeto não cobre 100% das iterações necessárias com o FIWARE". Adotar "100% do FIWARE" como métrica de objetivo é problemático: o ecossistema FIWARE inclui dezenas de Generic Enablers (Keyrock, Wilma, Cygnus, IoT Agents para múltiplos protocolos, entre outros) além dos três componentes do diagrama do projeto — um alvo de "100% do FIWARE" não é logicamente atingível nem foi o que o diagrama de referência definiu.

## Decisão

Reformular o objetivo de cobertura como **"cobertura completa do backend de referência definido no diagrama do projeto"**: Orion Context Broker + IoT Agent MQTT + componente de histórico (QuantumLeap, ver ADR-0003) + bancos de dados associados. Este é o escopo fechado e defensável adotado no Bloco 5 do plano de refatoração, não uma cobertura genérica de "todo o FIWARE".

## Alternativas consideradas

- **Manter a formulação "cobrir 100% do FIWARE" como objetivo do projeto** — descartada: é uma meta indefinida e não verificável; uma banca técnica identificaria a imprecisão, e não há como demonstrar "100%" de um ecossistema aberto e em expansão.
- **Restringir ainda mais o escopo, cobrindo só o Orion (situação atual)** — descartada: não atende ao caso de uso central do projeto, que depende de provisionamento real de dispositivos (IoT Agent) e consulta de histórico (QuantumLeap) — ambos ausentes hoje.

## Consequências

**Positivas:**
- Objetivo mensurável e defensável: dá para demonstrar, de forma binária, se o backend de referência foi ou não coberto.
- Evita a armadilha de escopo infinito ("sempre existe mais um Generic Enabler do FIWARE para cobrir").

**Negativas / trade-offs aceitos:**
- Exige documentar explicitamente, na monografia, que "backend de referência do diagrama" é uma escolha deliberada de escopo, e não a totalidade do ecossistema FIWARE — para evitar a impressão de que o objetivo foi "reduzido" por conveniência.
