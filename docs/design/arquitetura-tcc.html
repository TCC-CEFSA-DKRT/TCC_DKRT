Arquitetura do Auditor FIWARE

Como o front-end Angular, a API FastAPI e o SLM local (Ollama/Qwen2.5) se conectam para interpretar comandos em linguagem natural e auditar entidades no FIWARE Orion — cobrindo os dois caminhos em que o SLM é usado: interpretação síncrona de comandos e diagnóstico assíncrono de nível 2.

Frontend

Angular · TypeScript
  • Envia comandos em linguagem natural para /audits/interpret e submete auditorias com POST /audits.
  • Acompanha o progresso por polling (5s) em /audits/{id}/progress ou por SSE em /stream.
  • Tela de Catálogo lista e filtra os Smart Data Models sincronizados, com visualização do schema de cada um.

API

FastAPI · Postgres
  • Camada de interfaces (REST/CLI) sobre casos de uso da aplicação, seguindo arquitetura hexagonal.
  • Enfileira AuditJob e responde 202 Accepted imediatamente — a auditoria roda fora do request.
  • CatalogSyncScheduler mantém o catálogo de modelos atualizado automaticamente, sem comando manual.

SLM

Ollama · Qwen2.5 · local
  • Uso 1 — síncrono: interpreta o comando do usuário e devolve uma estrutura de auditoria, no caminho de request da API.
  • Uso 2 — assíncrono: diagnóstico de Nível 2 dentro do Worker, acionado só quando a validação estrutural não é conclusiva.
  • No Nível 2, é aterrado por RAG — contexto recuperado do próprio Postgres (pgvector).
