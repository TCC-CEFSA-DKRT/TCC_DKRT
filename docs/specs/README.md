# Specs de fase

Cópia versionada de `.cursor/specs/` (essa pasta continua existindo localmente, só não é
rastreada pelo git — ver `.gitignore`). Código que aponta pra `.cursor/specs/faseN.spec.md`
em comentário antigo ou docstring se refere ao mesmo conteúdo que está aqui.

`fase1.spec.md` a `fase10.spec.md` — especificação de comportamento por fase, a fonte mais
próxima do código (ver `README.md` da raiz e `docs/plano_refatoracao_v3.md`).
